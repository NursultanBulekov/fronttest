# Telegram-чат на React с GREEN-API

Минимальный пользовательский интерфейс Telegram-чата, разработанный на React в рамках тестового задания.

## Возможности

- вход с помощью `idInstance` и `apiTokenInstance`;
- проверка состояния и настроек Telegram-инстанса;
- создание чата по номеру телефона получателя;
- отправка текстовых сообщений методом `SendMessage`;
- получение входящих сообщений методами `ReceiveNotification` и `DeleteNotification`;
- отображение отправленных и полученных сообщений в интерфейсе чата.

## Запуск проекта

Установите зависимости:

```bash
npm install
```

Запустите проект в режиме разработки:

```bash
npm run dev
```

После запуска откройте адрес, указанный Vite в терминале.

## Данные для входа

Введите значения `idInstance` и `apiTokenInstance` из личного кабинета GREEN-API.

Номер получателя необходимо вводить в международном формате, без пробелов и символа `+`. Например:

```text
77001234567
```

## Настройка получения входящих сообщений

Для получения сообщений через HTTP API необходимо правильно настроить инстанс в личном кабинете GREEN-API:

1. Откройте нужный инстанс.
2. Нажмите кнопку **«Изменить»**.
3. Включите настройку получения входящих сообщений — `incomingWebhook` должна иметь значение `yes`.
4. Оставьте поле `webhookUrl` пустым.
5. Сохраните изменения.
6. Убедитесь, что инстанс авторизован и имеет состояние `authorized`.

Если `incomingWebhook` выключена или в поле `webhookUrl` указан адрес, приложение не сможет получать сообщения методом `ReceiveNotification`. При входе приложение проверяет эти настройки и выводит понятное сообщение об ошибке.

## Работа приложения

После входа приложение проверяет, что указанные данные принадлежат Telegram-инстансу. При создании нового чата метод `CheckAccount` проверяет наличие Telegram-аккаунта у получателя и возвращает его `chatId`. Этот идентификатор используется для отправки сообщений и сопоставления входящих ответов.
